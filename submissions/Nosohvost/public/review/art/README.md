# Optional artwork proposals

Review assets only. No game sprites or game code are replaced. All SVGs are self-contained, transparent, and use the existing dark purple ink (`#1b1430`).

| File | Concept |
| --- | --- |
| `duck-alt.svg` | Confident mallard: swept tuft, knowing eyebrow, strutting feet and a clearer cobalt wing flash. |
| `goose-alt.svg` | Aggressive Canada goose: serpentine neck, raised feathered wing and an unmistakable open honk. |
| `bug-alt.svg` | Mischievous beetle: six hooked legs, split lime shell, spring antennae and a crooked grin. |
| `prod-alt.svg` | Production on fire: leaning server rack, alarm eyes, uneven drawers, stomping feet and a curling flame. |
| `segfault-alt.svg` | Broken memory shard: fractured violet planes, one crossed eye, one wild eye and cyan/magenta channel offsets. |
| `rubber-duck-alt.svg` | Friendly debugging companion: plump toy silhouette, curled tuft, smiling bill and warm plastic highlights. |
| `deadline-current.svg` | Current canvas clock faithfully transcribed at `time = 0`, progress zero, 23:00, no rage/lunge/push/flash; HUD excluded. Geometry uniformly scaled by 0.8, translated to (160,166). SVG blur approximates the canvas red shadow. |
| `deadline-alt.svg` | Option A: keep The Deadline. Battered brass, asymmetric dial, quivering bells, frantic eyes and a toothy shout make the same idea more expressive. |
| `scope-creep.svg` | Option B: the specification becomes the monster. Expanding paper layers, binder-clip horns, folded claws, torn teeth, revision marks and sticky-note requests. |

Sprites: `viewBox="0 0 120 120"`. Bosses: `viewBox="0 0 320 320"`. Sprites retain the originals' rightward orientation and strong small-scale outlines. Shapes are hand-authored SVG paths, with minimal gradients reserved for bosses. No external fonts, images, scripts or linked assets are required.

Only the redesigned clock bells and two Scope Creep notes use subtle SMIL motion; their base geometry is complete when animation is unavailable. The current-clock comparison is deliberately static.

Direction: keep The Deadline for the strongest connection to the one-hour premise. Scope Creep is the more distinctive alternate villain, especially if feature requests or project growth become part of the story. Both boss options are proposals for review, not game integrations.
